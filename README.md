# Petals & Blooms Florist

Artisan Floral Arrangements website featuring interactive floral showcase, smooth parallax animations, responsive navigation, and customer order forms.

## Features
- **Artisan Product Catalog**: Showcasing floral bouquets with dynamic interactions.
- **Scroll Sync Experience**: Canvas-based interactive sequence animations.
- **Responsive Design**: Polished for desktop, tablet, and mobile displays.
- **Security Hardening**: Hardened HTTP security headers and protected directory indexing.

## Structure
- `public_html/` - Web root containing HTML, CSS, JavaScript, and media assets.
- `public_html/.htaccess` - Production security rules and headers.
